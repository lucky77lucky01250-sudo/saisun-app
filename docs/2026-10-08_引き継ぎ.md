### 方式
**ローカル優先＋全件同期。** 入力はこれまでどおりlocalStorageへ即保存し、
通信できるときに `POST /api/sync` で全件を送受信してつき合わせる。

- **家族コード**: 英数字12桁（紛らわしい `I O 0 1` を除く32文字＝約60ビット）。
  同じコードの端末どうしで共有される。**アカウント登録もパスワードも無い**
- **参加方法**: 設定タブ →「共有リンクを送る」で `/?code=…` を渡す。
  コードを持たない端末はそのリンクで自動参加。持っている端末は勝手に乗り換えず設定タブで本人に確認させる
- **競合**: `updatedAt`（ミリ秒）が新しい方を採用する後勝ち
- **削除**: 物理削除せず `deleted` の印を立てる（消すと相手の同期で復活するため）
- **同期のきっかけ**: 起動時／履歴・設定タブを開いたとき／アプリに戻ったとき／最後の変更から8秒後／手動ボタン。
  30秒のクールダウンあり

### 追加したファイル
| ファイル | 役割 |
|---|---|
| `app/lib/entry.ts` | 型・家族コード生成・正規化・行変換。**入力画面と同期APIが共有**。片方だけ直すと同期が壊れる |
| `app/api/sync/route.ts` | 同期の唯一の出入口。Supabaseの鍵はここだけが持つ |
| `app/manifest.ts` | PWA（ホーム画面に追加） |
| `scripts/make-icons.py` | アイコン生成。`python3 scripts/make-icons.py` |

`app/page.tsx` に設定タブ（共有・同期・JSON書き出し）を追加。タブは3つになった。

## 4. ⚠️ 踏みやすい罠（全部ここで実際に踏んだ）

### pushしても自動デプロイされない
**このプロジェクトはVercelのGitHub連携がされていない。** `git push` だけでは本番に出ない。

```bash
cd ~/Projects/saisun-app && npx vercel --prod
```

case7-rag-slack で踏んだのと同じ罠。GitHub連携へ切り替えるかは未決。

### ホーム画面アプリとSafariタブは別の保存箱
iOSの仕様。同じURLでもデータは共有されない。
**ホーム画面に追加した直後は履歴が0件に見える。** 設定タブで家族コードを入れれば戻る。

→ 2026-10-05に奥さんの端末で実際に発生。コード入力で解決済み。
→ **アイコンを消して追加し直す前に、必ず同期を済ませること。** 同期前に消すとデータが消える。

### iOS Safariの7日ルール（ITP）
タブで開いたサイトのlocalStorageは、7日アクセスが無いと消えることがある。
採寸日と出品日が別日になる使い方なので実害がある。
**PWA化はこれを避けるためでもある。ホーム画面から開く運用を崩さない。**

### ESLintの誤検知
`Date.now()` に `react-hooks/purity` の error が3件出る。
イベントハンドラ内の呼び出しをReact Compilerが描画中と誤認しているだけ。
**同期機能を入れる前から2件出ていた。ビルドは通る。**

### 127.0.0.1 では開発サーバーのテストができない
Next.jsが別オリジン扱いで403を返し、**Reactが起動しない**（＝同期も動かない）。
2台目を模擬するなら `localStorage.clear()` してから `?code=…` で開く。
